# 每日喝水提醒 · Daily Water Reminder

一个单文件、零依赖的喝水提醒网页，打开就能用，所有记录只保存在你自己的浏览器里。

## 在线访问

👉 **https://kenkloong.github.io/water-reminder/**

（GitHub Pages 部署，手机电脑都能打开，可添加到主屏幕当小应用用。）

## 功能

- **今日目标**：默认 2000 ml，可在页面里随时修改
- **一键记录**：点「喝一杯」记 250 ml，也可撤销一杯或清空今日
- **进度可视化**：进度条 + 已喝毫升数 + 已喝杯数，达标有祝贺提示
- **定时提醒**：间隔可选 30 / 60 / 90 / 120 分钟，开启后到点弹浏览器通知（Notification API）；浏览器未授权通知时自动降级为页面内横幅提示
- **本地保存**：用 localStorage 保存当天记录，按日期分开存储，跨天自动重置，不上传任何数据

## 使用说明

1. 打开上面的网址
2. 需要提醒的话，点「开启提醒」，浏览器询问通知权限时点允许（不允许也能用，只是改成页面内提示）
3. 每喝完一杯水，点一下「喝一杯」

## 技术

- 纯原生 HTML + CSS + JavaScript，全部写在一个 `index.html` 里，无框架、无构建、无外部请求
- 托管在 GitHub Pages
